## Problem Description

All 16 instances from the 1996 Beijing SAT Competition benchmark collection (combinatorial, graph, and planning encodings).

## Corpus & Data Sizes (Four Formats)

- **`cnf-orig/`** — 16 original native **DIMACS `.cnf.xz`** files (637.2 KB).
- **`aig-converted/`** — 16 exact **Binary AIGER 1.9 `.aig.xz`** conversions (1.05 MB, verified via [Berkeley ABC](https://github.com/berkeley-abc/abc) `read_aiger`).
- **`xcnf-converted/`** — 16 lossless **[CryptoMiniSat](https://github.com/msoos/cryptominisat) `.xcnf.xz`** conversions (623.8 KB, `0` extracted native XOR parity clauses).
- **`anf-converted/`** — 16 lossless linear-size **DIMACS-ANF `.anf.xz`** conversions (1.92 MB, generated via [`../src/to_anf.py`](../src/to_anf.py)).
- **`src/`** — Standalone converters (`cnf2aig.py`, `cnf2xcnf.py`).
