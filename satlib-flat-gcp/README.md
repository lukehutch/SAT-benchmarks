## Problem Description

Stratified sample of 8 instances (`flat30` through `flat200`) from the 1,700-instance SATLIB flat 3-colourable graph coloring ensemble (full archive URLs in [`../satlib-archive-uris/`](../satlib-archive-uris/README.md)).
